REPL = Read → Evaluate → Print → Loop

Both the Browser DevTools Console and Node.js provide a REPL experience.

Browser DevTools Console

- Read → Reads the JavaScript you type.
- Evaluate → JavaScript engine evaluates it.
- Print → Displays the result.
- Loop → Waits for your next command.
- Runs JavaScript in the browser environment.
- Has access to browser features such as document, window, DOM APIs, etc.

 Node.js REPL

- Also follows Read → Evaluate → Print → Loop.
- Runs JavaScript in the Node.js runtime.
- Has access to Node.js features such as file-system and networking APIs.
- Does not have browser-specific objects like window and document.

🔥 Key Interview Point

Both browser DevTools and Node.js provide a REPL experience, but they run JavaScript in different environments with different APIs.

Browser → JavaScript Engine + Web APIs

Node.js → V8 Engine + Node.js APIs

⭐ FINAL SIMPLE LINE
Internal script → no server request, unless your code fetch something
External script (src) → browser sends request to server to get the JS file
